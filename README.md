# SOC N2 Portfolio

Technical portfolio focused on Security Operations Center (SOC) activities, with an emphasis on security event analysis, incident investigation, artifact analysis, and security tools.

## About This Project

This repository contains practical labs and security analyses performed in isolated and virtualized environments, demonstrating technical knowledge applicable to the daily activities of a SOC Analyst.

## Contents

* Security Event Analysis
* Log Analysis
* Incident Investigation
* Network Traffic Analysis
* Malware Analysis
* IOC Analysis
* Security Tools and Technologies

## Lab Environment

* REMnux
* Kali Linux
* Windows Virtual Machine
* VirtualBox

## Objective

Demonstrate practical technical skills related to the identification, investigation, analysis, and documentation of security events and potential incidents.
